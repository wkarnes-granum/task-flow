What happens when you add a task

1

You type and click "Add"

The event listener in script.js catches the form submit and calls addTask()

2

Browser sends a request

fetch('/api/tasks', { method: 'POST' }) sends the task text to the server as JSON

3

Server receives and processes it

Express matches the request to app.post('/api/tasks') in server.js, creates a task object with an ID

4

Server saves to disk

writeTasks() writes the updated task list to tasks.json using Node's file system

5

Browser updates the screen

The server responds with the new task. JavaScript adds it to the list and render() rebuilds the UI

Before (no back-end)

You click "Add"
↓
script.js saves to localStorage
↓
UI updates

Now (with back-end)

You click "Add"
↓
script.js sends fetch() to server
↓
server.js saves to tasks.json
↓
